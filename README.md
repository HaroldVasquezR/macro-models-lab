# Computational Macroeconomics Laboratory

**Macroeconomics I & II | Harold Vásquez, Ph.D.**

A computational laboratory designed to complement the study of macroeconomic theory through numerical modeling, simulation, and reproducible economic analysis.

The laboratory supports _Macroeconomics I_ (Economic Growth) and _Macroeconomics II_ (Business Cycles and Macroeconomic Policy).

## Learning Approach

The learning sequence begins with computational foundations and _Macroeconomics I_ models. After completing this stage, students progress to _Macroeconomics II_ applications.

The laboratory introduces GNU Octave and progressively incorporates Dynare and other computational tools.

## Repository Organization

| Directory | Purpose |
|---|---|
| `docs/` | Installation guides, GitHub Desktop instructions, and documentation |
| `common/` | Shared computational foundations and introductory exercises |

## Computational Topics

### Common Foundations
- Introduction to GNU Octave
- Matrix algebra and numerical methods
- Reproducible computational workflows

### Macroeconomics I
- Keynesian model and two-period model
- Cobb-Douglas production function
- Solow growth model: non-stochastic and stochastic
- AK and endogenous growth models
- Romer
- Ramsey models: closed and open-economy
- Introduction to Dynare

### Macroeconomics II
- IS–MP–Phillips framework
- Real Business Cycle models
- New Keynesian models
- Small open economy models
- Monetary and fiscal policy simulations

The topics listed above describe the planned curriculum, not necessarily materials currently available in the repository.

## Getting Started

1. Install GitHub Desktop and Visual Studio Code.
2. Clone this repository to your computer.
3. Read the documentation and installation instructions.
4. Install GNU Octave before running Octave-based exercises.
5. Use GitHub Desktop to obtain repository updates.

Students may clone and update this public repository without write access. They should complete their own exercises in separate working copies or personal repositories.
