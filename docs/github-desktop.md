# GitHub Desktop: Student Quick Guide

## Essential Concepts

- **Repository:** a project with files and version history.
- **Clone:** download a local working copy of a repository.
- **Commit:** record changes in the local repository.
- **Push:** send local commits to GitHub, when authorized.
- **Fetch:** check for and download remote updates.
- **Pull:** incorporate remote changes into the local branch.

## How to Update Course Materials

1. Open GitHub Desktop.
2. Select `macro-models-lab` under **Current Repository**.
3. Check that **Current Branch** is `main`.
4. Verify that there are no unexpected local changes.
5. Click **Fetch origin**.
6. If **Pull origin** appears, click it.
7. Open the updated materials in Visual Studio Code.

## Student Permissions

This repository is public.

Students may:
- View and download the materials.
- Clone the repository.
- Receive updates.
- Modify their own local copies.

Students do not have permission to push changes to the
instructor's repository.

## Troubleshooting

**I cannot find my files:** In GitHub Desktop, select
**Repository > Show in Finder** on macOS or
**Repository > Show in Explorer** on Windows.

**I cannot see the latest materials:** Check the selected
repository and branch, then use Fetch and Pull.

**GitHub Desktop shows modified files:** Save your work
elsewhere and ask for assistance before discarding changes.

**I cannot push:** Students are not expected to push changes
to the instructor's repository.

## Security

Never share passwords, authentication codes, access tokens,
or private student information.
