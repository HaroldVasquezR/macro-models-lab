## Objetivo

Familiarizarse con GNU Octave y aprender a realizar
operaciones computacionales básicas.

## Materiales

1. [Presentación de la Unidad 0](Introduccion_Modelos_Computacionales_Matlab_Octave.pdf)
2. [Código introductorio](code/intro_octave.m)

## Cómo comenzar

1. Instala GNU Octave desde https://octave.org/.
2. Descarga o clona el repositorio del laboratorio.
3. Abre la presentación PDF.
4. Abre GNU Octave.
5. Examina el archivo `intro_octave.m`.
6. Ejecuta los ejemplos siguiendo las instrucciones
   de la presentación.

## Recomendaciones

- Trabaja con una copia personal del código.
- Lee los comentarios antes de ejecutar cada sección.
- Modifica los ejemplos y observa los resultados.
- No necesitas utilizar Git desde la terminal.
