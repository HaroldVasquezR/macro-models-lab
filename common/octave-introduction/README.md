# Introduction to GNU Octave

**Status: In preparation**

## Purpose

This module will introduce the basic computational tools needed
for the Macroeconomics I and II laboratory.

## Planned Topics

- GNU Octave installation and interface
- Variables and basic calculations
- Vectors and matrices
- Scripts and functions
- Basic numerical operations
- Graphs and visualization
- Running and verifying economic examples

## Requirements

GNU Octave must be installed before running the exercises.

Official website: https://octave.org/

## Materials

Code, examples, exercises, and reference results will be added
after development and validation.
