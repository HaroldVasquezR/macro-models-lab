# Getting Started
Welcome to the Computational Macroeconomics Laboratory.

## Requirements
- A computer running Windows or macOS
- GitHub Desktop
- Visual Studio Code
- GNU Octave for Octave-based exercises
- An internet connection to download updates
- **Willingness to learn!**

## Accessing the Materials
1. Open the repository on GitHub:
   https://github.com/HaroldVasquezR/macro-models-lab
2. Select **Code** and open the repository in GitHub Desktop,
   or clone it using **File > Clone        Repository** in GitHub Desktop.
3. Chose a local folder and complete the cloning process.
4. Open the repository in Visual Studio Code.
(_Note: it's useful to save all your cloned repositories in a local folder `docs/GitHub/`_)

## Receiving Updates
1. Open GitHub Desktop.
2. Select the `macro-models-lab` repository.
3. Select the `main` branch.
4. Click **Fetch origin**
5. If updates are available, click **Pull origin**.

If you have modified repository files locally, ask for assistance before pulling updates.

## Working on Exercises
Do not edit the instructor's original exercise files.

Copy the exercise files into a separate personal working folder or personal repository before making modifications.

**DO NOT WORRY:** Your local modifications do not change the instructor's repository. 

## Computational Software
GNU Octave is required to run Octave examples.
Installation instructions and tested exercises will be added progressively.
